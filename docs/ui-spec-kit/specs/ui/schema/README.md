# Schema

Отдельной XSD-схемы нет — единственный исполняемый источник грамматики UISpec — `tools/uispec/validate_uispec.py` (проверки V1–V11, спецификация — `AUDIT.md` П2). `uispec.xsd` удалён решением аудита (находка C6): stdlib-инструментов для XSD-валидации нет, и схема-заглушка лишь изображала проверку. Её содержательное правило — обязательный атрибут `version=` корневого элемента — перенесено в валидатор.
