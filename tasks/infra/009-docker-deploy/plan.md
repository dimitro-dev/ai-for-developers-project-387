фиксируются в `result.md`.

- [ ] `make -C apps/api gates` — P03–P05

## Блокеры и открытые вопросы

- **Согласование гейтов дано авансом.** Владелец 2026-08-18: «даю согласие на спеки, прошедшие
  ревью» — покрывает `plan` при условии ревью перед `approve`. Гейт `result` этим согласием не
  покрыт и принимается владельцем обычным порядком.
- **P10 требует владельца.** Создание сервиса на Render (или Railway) — аккаунт и подтверждение
  владельца; всё до P10 включая MR готовится без него. До выполнения P10 задача не закрывается:
  AC8/AC9 не проверить.
- **Docker локально — через colima.** Проверки P07/P09 требуют запущенного демона
  (`colima start`, см. `infra/README.md`). Если демон недоступен, сборочные проверки блокируются
  до его старта — это блокер проверки, не кода.
- **Время сборки образа** (NFR7): два `expo export --clear` без кеша. Компромисс принят в ADR §2
  и «Последствиях»; если ручной прогон окажется непрактичным, фиксируется в `result.md` числом.
- **Квирк npm с манифестами** (ADR §1): рантайм-этап копирует только манифесты цепочки API —
  полный набор протаскивает dev-зависимости вопреки `--omit=dev`. Состав манифестов зафиксирован
  в P06; AC11 проверяет результат.
